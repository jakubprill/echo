# Notes for AI assistants

Follow [CONTRIBUTING.md](CONTRIBUTING.md). In short:

- Write everything in the repository in English (file names, code, comments, docs, commits, PRs). Only the app's user-facing strings are Polish.
- Never commit copyrighted vocabulary decks; the repository is public.
- Keep `app/src/core/` platform-free and run `cd app && npm test` before opening a PR.
- Delete merged branches.
